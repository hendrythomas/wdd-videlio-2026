# WDD Meesterproef Videlio

Videlio is een stichting die zich inzet voor de onafhankelijkheid van blinden of slechtzienden.
Het is een community die blijft groeien en elkaar blijft inspireren.

Voor onze schoolopdracht mogen wij voor deze stichting een nieuwe website ontwikkelen.
We willen met onze website echt 'Videlio' uitstralen; Iedereen is welkom en kan bijdragen.

Als je meer wilt weten over dit project kun je onze [wiki](https://github.com/hendrythomas/wdd-videlio-2026/wiki)  bekijken.

## Hoe run je dit project?

Om dit project te runnen moet je node package manager (npm) geïnstalleerd hebben.

Zodra je npm geïnstallerd hebt kun je via de volgende commands het project lokaal draaien.

1. 'npm i' -> installeer je dependencies
2. 'npm run dev' -> start een lokale dev server

### Lijst van alle commands
| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
